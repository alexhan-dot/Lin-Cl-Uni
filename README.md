# 리니지 클래식 대학교

정적 랜딩 페이지입니다. `index.html`을 브라우저에서 바로 열거나 GitHub Pages, Vercel, Netlify 같은 정적 호스팅에 배포할 수 있습니다.

## 파일 구성

- `index.html`: 공개 사이트
- `admin.html`: 가격, 상담 링크, 주요 문구를 수정하는 관리자 페이지
- `site-data.js`: 공개 사이트가 읽는 기본 데이터
- `script.js`: 공개 사이트 렌더링과 카카오톡 상담 연결
- `admin.js`: 관리자 저장, JSON 적용, 배포용 데이터 파일 다운로드
- `styles.css`: 공개 사이트 공통 스타일
- `admin.css`: 관리자 페이지 스타일
- `assets/hero-campus.png`: 히어로 비주얼

## 가격 수정 절차

1. `admin.html`을 엽니다.
2. `수강료 카드`에서 과정명, 가격, 설명, 추천 표시를 수정합니다.
3. `저장`을 누르면 같은 브라우저의 `index.html` 미리보기에 반영됩니다.
4. 실제 배포에 반영하려면 `배포용 site-data.js 다운로드`를 누른 뒤 기존 `site-data.js`와 교체합니다.

## 상담 링크 설정

관리자 페이지의 `카카오톡 상담 링크`에 실제 오픈채팅 또는 카카오톡 채널 상담 URL을 입력합니다.

- 오픈채팅 예: `https://open.kakao.com/o/실제코드`
- 채널 상담 예: `https://pf.kakao.com/_채널ID/chat`

## 참고

이 관리자 페이지는 정적 사이트용 편집 도구라서 서버 로그인이나 데이터베이스 저장 기능은 없습니다. 공개 배포값은 최종적으로 `site-data.js` 파일을 교체해야 바뀝니다.
